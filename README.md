# 🐱 Zuko y Lila - Mod para Stardew Valley

Mod de SMAPI para **Stardew Valley 1.6+** que añade a **Zuko** y **Lila** como compañeros que te siguen por todo el valle, suben su nivel de cariño contigo y te traen regalos aleatorios.

---

## 📥 Descarga e Instalación

👉 **[Descargar última versión (v1.0.0) aquí](https://github.com/SherCrisSC/ZukoYLilaMod/releases/latest)**

### Requisitos
* [Stardew Valley](https://www.stardewvalley.net/) (v1.6 o superior)
* [SMAPI](https://smapi.io/) (v4.0.0 o superior)

### Pasos de instalación
1. Descarga el archivo `ZukoYLilaMod-v1.0.0.zip` desde la sección de [Releases](https://github.com/SherCrisSC/ZukoYLilaMod/releases).
2. Descomprime el archivo y copia la carpeta `ZukoYLilaMod` dentro de la carpeta `Mods` de tu instalación de Stardew Valley.
3. Inicia el juego mediante SMAPI.
